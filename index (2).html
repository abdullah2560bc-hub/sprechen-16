دليل استخدام مصحح الألمانية السياقي الطلقة ⚡

• التملية الصوتية الذكية (القسم ١): تحدث بالألمانية أو العربية؛ الكابيتال وعلامات الترقيم تُضبط تلقائياً بدون احتسابها كأخطاء.

• التشطيب السياقي الدقيق (القسم ٢): يشطب فقط على أخطاء القواعد والسياق والمتلازمات اللفظية.

• معنى الكلمة الفوري + زر الصوت (القسم ٣): اضغط على أي كلمة ألمانية في الجزء الأخضر ليظهر لك معناها بالعربي فوراً وبجانبها زر الصوت 🔊 وزر حفظها في الحافظة.

• الحافظة الدائمة الذكية (القسم ٦): تحتفظ بكل كلماتك وجملك وترجماتها العربية وأمثلتها المنسدلة داخل المتصفح دائماً حتى لو أغلقت المتصفح أو الجهاز.

٥ رادار قواعد الجرامر والتراكيب السياقية (B2 / C1 / C2) — شرح مختصر
vorhin habe ich B2 — تقديم الفعل في المركز الثاني (Inversion - Position 2)
• عند بدء الجملة بظرف زمان أو حال (vorhin / leider) يأتي الفعل المصرف فوراً في المركز الثاني قبل الفاعل.
daran gearbeitet B2 — الظروف الضميرية مع الأفعال (Pronominaladverbien: daran / darauf)
• الفعل (arbeiten an + Dativ) يستخدم مع غير العاقل الضمير الظرفي (daran = العمل عليه).
zufriedenstellend B2 / C1 — اسم الفاعل كصفة لغير العاقل (Partizip I: zufriedenstellend)
• نستخدم (zufriedenstellend = مُرضٍ) لوصف النتائج أو العمل، بينما (zufrieden = راضٍ) لوصف شعور الإنسان فقط.
wieso das passiert ist B1 / B2 — السؤال غير المباشر (Indirekter Fragesatz mit wieso)
• أداة الاستفهام (wieso / warum) في وسط الجملة تحولها لجملة جانبية وترسل الفعل المصرف إلى النهاية.
